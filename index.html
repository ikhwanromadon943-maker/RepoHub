How to get a Personal Access Token

A token connects RepoHub to your GitHub account securely, without ever sharing your password.

  1. 1

    Open github.com/settings/tokens/new

  2. 2

    Name the token and set a short expiration date (30–90 days is recommended)

  3. 3

    Check the repo scope so RepoHub can read and write repositories

  4. 4

    Generate the token, copy it, and paste it into the "Connect GitHub" button

Never share your token with anyone. Treat it like a password — anyone with it can access your repositories according to the scopes you granted.

SECURITY

Security Center

Review how RepoHub protects your credentials and data.

Local-only token storage

Your Personal Access Token is stored exclusively in this browser's local storage. It is never transmitted to any server except api.github.com, and RepoHub has no backend of its own that could log or leak it.

HTTPS-only communication

All requests use TLS-encrypted HTTPS. The token field is masked by default, and content pasted into it is never logged, cached, or written to browser history.

Output sanitization

All repository names, file names, commit messages, and issue content are escaped before being rendered, preventing malicious content from a repo or file name executing in your browser.

External links are safe by default

Every outbound link opens with rel="noopener noreferrer", preventing the destination page from accessing this tab or your referrer data.

Recommended practices

  • Use fine-grained tokens scoped to specific repositories when possible.
  • Set short token expirations (30–90 days) and rotate regularly.
  • Revoke this token immediately from GitHub settings if this device is lost or shared.
  • Never paste your token into any site other than RepoHub or github.com.
