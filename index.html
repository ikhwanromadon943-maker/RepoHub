Cara mendapatkan Personal Access Token

Token dipakai untuk menghubungkan RepoHarbor ke akun GitHub kamu secara aman.

  1. 1

    Buka github.com/settings/tokens/new

  2. 2

    Beri nama token, atur masa berlaku sesuai kebutuhan

  3. 3

    Centang scope repo agar RepoHarbor bisa membaca & menulis repo

  4. 4

    Generate token, salin, lalu tempel di tombol "Hubungkan GitHub"
